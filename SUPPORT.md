# Support

## Getting Help

If you need help with Bowling HQ, here are your options:

### Documentation

**Start here first:**
- [Quick Start Guide](docs/00_QUICK_START.md) - 15-minute introduction
- [Platform Overview](docs/01_PROJECT_OVERVIEW.md) - Full platform explanation
- [Documentation Index](docs/INDEX.md) - Complete reference

### Specific Topics

- **How do I get started?** → [Quick Start Guide](docs/00_QUICK_START.md)
- **What systems are available?** → [Platform Overview](docs/01_PROJECT_OVERVIEW.md)
- **How does [System] work?** → Check `/docs/` directory for detailed guides
- **How do I contribute ideas?** → [Contributing](CONTRIBUTING.md)

### Questions or Issues

1. **Search existing documentation** - Your answer may already be there
2. **Open a GitHub Issue** - Describe your question or problem clearly
3. **Include context** - What were you trying to do? What happened?
4. **Reference relevant documentation** - Links help us understand faster

### Types of Issues

**Bug Reports:**
- What you were doing
- What you expected to happen
- What actually happened
- Steps to reproduce

**Feature Requests:**
- What you want to accomplish
- Why it would be useful
- How it fits with the platform

**Documentation Questions:**
- What you're trying to understand
- What's unclear about the docs
- Suggestions for improvement

## Response Time

This is a personal project. Response times vary, but I'll do my best to:
- Acknowledge issues within a few days
- Provide initial guidance
- Work toward solutions

## Community

Feel free to:
- Share your ideas and feedback
- Suggest improvements
- Help others understand the platform
- Contribute documentation improvements

## Private Issues

If you have a security concern or private issue:
- Email directly (contact info in repository profile)
- Mark it as private if possible
- Avoid public discussion of security vulnerabilities
